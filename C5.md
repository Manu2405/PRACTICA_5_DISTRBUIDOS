# C5 — Las 5 Consultas de Datos al Clúster Cassandra

> **Entregable:** "5 Consultas de Datos al Dashboard o a la base de datos" (10 pts del PDF Práctica 5).
> **Ejecución:** todas se corren directo sobre el clúster Cassandra vía `docker exec`, sobre el keyspace `semapa`.
> **Datos:** 100.000 contratos, 248.055 lecturas, 3 períodos (2026-02, 2026-03, 2026-04).

---

## ℹ️ Nota técnica importante (para la defensa)

Cassandra está optimizada para consultas que conocen la **partition key**. Las consultas con agregación global (SUM, COUNT, AVG sobre toda la tabla) generan el warning `Aggregation query used without partition key` y requieren `ALLOW FILTERING` o agregación en el cliente. **Funcionan correctamente**, pero hacen un escaneo distribuido — esto es esperado y es el trade-off natural de un wide-column store.

Por eso, las consultas 4 y 5 (que agregan por una columna que no es partition key) combinan una query CQL + una agregación en el cliente (PowerShell o bash).

## Consulta 1 — ¿Cuál es el modelo de sensor que menos reporta?

**Interpretación:** "menos reporta" = el modelo con **más errores/fallas** de transmisión (reporta con menos confiabilidad). Se usa la tabla `errores_por_modelo_mes`.

### Comando CQL

```powershell
# Desde: cualquier directorio
docker exec semapa-cassandra cqlsh -e "USE semapa; SELECT periodo, modelo, SUM(cantidad) AS total_errores FROM errores_por_modelo_mes GROUP BY periodo, modelo;"
```

> 💡 `GROUP BY periodo, modelo` es válido en Cassandra porque `(periodo, modelo)` es la partition key de la tabla. Por eso esta consulta es eficiente.

### Resultado

```
 periodo | modelo              | total_errores
---------+---------------------+---------------
 2026-02 | ITC 100             |            84
 2026-02 | Siconia WATER WM-NB |            84
 2026-02 | OY1320 LoRaWAN      |            83
 2026-02 | WP20                |            83
 2026-02 | Medidor 100% IoT    |            83
 2026-03 | ITC 100             |            83
 ... (15 filas en total, 5 modelos × 3 períodos)
```

**Total de errores por modelo (sumando los 3 meses):**

| Modelo | Total errores |
|---|---|
| **ITC 100** | **249** ← el que más falla |
| WP20 | 248 |
| Siconia WATER WM-NB | 248 |
| OY1320 LoRaWAN | 248 |
| Medidor 100% IoT | 248 |

### ✅ Respuesta

El modelo **ITC 100** es el que menos reporta (más fallas): **249 errores** acumulados en los 3 meses, marginalmente por encima del resto (248). La distribución es muy pareja porque los errores se generaron balanceados entre los 5 modelos.

## Consulta 2 — ¿Cuál es el cliente con más contratos y cuánto paga en promedio?

**Interpretación:** identificar el titular (CI) con mayor cantidad de contratos a su nombre, y su pago promedio mensual.

### Paso 1 — Encontrar el cliente con más contratos

Son **2 comandos separados** (evita el infierno de comillas anidadas en PowerShell).

**Comando 1 — exportar los titulares a CSV (~1 min, escanea las 100k filas):**
```powershell
# Desde: cualquier directorio
docker exec semapa-cassandra cqlsh -e "USE semapa; COPY contratos_por_numero (identificador_titular) TO '/tmp/cis.csv';"
```

**Comando 2 — contar y ordenar (instantáneo, corre dentro del contenedor):**
```powershell
# Desde: cualquier directorio
docker exec semapa-cassandra bash -c "sort /tmp/cis.csv | uniq -c | sort -rn | head -5"
```

> ⚡ **Por qué así:** el conteo por titular requiere escanear las 100.000 filas (porque `identificador_titular` NO es la partition key — la PK es `numero_contrato`). Para que no sea lento: (1) `COPY ... TO` exporta a CSV crudo en vez de `SELECT` que formatea tabla por tabla, y (2) el conteo con `sort`/`uniq` corre **dentro del contenedor**, evitando transferir 100k filas al host y el lento `Group-Object` de PowerShell. Una vez creado `/tmp/cis.csv`, el comando 2 se puede repetir al instante.

**Resultado:**
```
     13 1920129 CBBA   ← el máximo
     12 3757338 CBBA
     11 9639998 CBBA
```
El CI `1920129 CBBA` tiene **13 contratos** (el máximo).

### Paso 2 — Ver sus contratos y promedio de pago

```powershell
# Desde: cualquier directorio
docker exec semapa-cassandra cqlsh -e "USE semapa; SELECT numero_contrato, nombre_titular FROM contratos_por_numero WHERE identificador_titular='1920129 CBBA';"

docker exec semapa-cassandra cqlsh --request-timeout=120 -e "USE semapa; SELECT COUNT(*) AS num_contratos, AVG(monto_bs) AS promedio_bs FROM consumo_mensual_por_contrato WHERE identificador_titular='1920129 CBBA' ALLOW FILTERING;"
```

### Resultado

```
 num_contratos | promedio_bs
---------------+-------------
            13 |       84.86
```

### ✅ Respuesta

El cliente con más contratos es **Ángel Cervantes Cuesta** (CI `1920129 CBBA`), con **13 contratos**, y un pago promedio de **84.86 Bs**.

## Consulta 3 — ¿Cuánta agua se consumió en algún distrito por mes?

**Interpretación:** total de consumo (m³) de un distrito específico en un período. Ejemplo: Distrito 5 en 2026-04.

### Comando CQL

```powershell
# Desde: cualquier directorio
docker exec semapa-cassandra cqlsh --request-timeout=120 -e "USE semapa; SELECT SUM(consumo_m3) AS total_m3, COUNT(*) AS contratos FROM consumo_mensual_por_contrato WHERE distrito='Distrito 5' AND periodo='2026-04' ALLOW FILTERING;"
```

> Puedes cambiar `'Distrito 5'` y `'2026-04'` por cualquier distrito (Distrito 1 a 15) y período (2026-02, 2026-03, 2026-04).

### Resultado

```
 total_m3 | contratos
----------+-----------
   128392 |      2962
```

### ✅ Respuesta

En **Distrito 5**, durante **2026-04**, se consumieron **128.392 m³** de agua, distribuidos en **2.962 contratos**.

## Consulta 4 — ¿Quién es la persona que más debe?

**Interpretación:** el titular con mayor deuda acumulada (suma de facturas con `estado_facturacion = 'vencido'`).

### Comando CQL + agregación

**PowerShell (laptop A — Windows):**
```powershell
# Desde: cualquier directorio
docker exec semapa-cassandra cqlsh --request-timeout=120 -e "USE semapa; SELECT identificador_titular, nombre_titular, monto_bs FROM consumo_mensual_por_contrato WHERE estado_facturacion='vencido' ALLOW FILTERING;" |
  Select-String '\|' | Select-Object -Skip 1 |
  ForEach-Object { $p = $_.ToString().Split('|'); if ($p.Count -ge 3 -and $p[2].Trim() -match '^[\d.]+$') { [PSCustomObject]@{ CI=$p[0].Trim(); Nombre=$p[1].Trim(); Monto=[double]$p[2].Trim() } } } |
  Group-Object CI |
  ForEach-Object { [PSCustomObject]@{ CI=$_.Name; Nombre=$_.Group[0].Nombre; TotalDeuda=[math]::Round(($_.Group.Monto | Measure-Object -Sum).Sum,2) } } |
  Sort-Object TotalDeuda -Descending | Select-Object -First 5
```

**bash (laptop B — Linux):**
```bash
# Desde: cualquier directorio
docker exec semapa-cassandra cqlsh --request-timeout=120 -e "USE semapa; SELECT identificador_titular, nombre_titular, monto_bs FROM consumo_mensual_por_contrato WHERE estado_facturacion='vencido' ALLOW FILTERING;" \
  | tail -n +4 | head -n -2 \
  | awk -F'|' 'NF>=3 { key=$1"|"$2; gsub(/^ +| +$/,"",$3); sum[key]+=$3 } END { for (k in sum) printf "%.2f|%s\n", sum[k], k }' \
  | sort -rn | head -5
```

### Resultado (top 5 deudores)

```
568.54 Bs | 1841829 CBBA | Geraldo Aragón-Valls
466.90 Bs | 1668701 CBBA | Milagros Aragón Gimeno
442.34 Bs | 5246874 CBBA | Fabio Amores Moll
425.02 Bs | 2079212 CBBA | América Amo Ponce
393.22 Bs | 6773674 CBBA | Claudia Delia Amorós Noguera
```

### ✅ Respuesta

La persona que más debe es **Geraldo Aragón-Valls** (CI `1841829 CBBA`), con una deuda acumulada de **568.54 Bs** en facturas vencidas.

## Consulta 5 — ¿Cuál de las 4 categorías residenciales recoge más plata en cualquier mes?

**Interpretación:** de las categorías residenciales (R1, R2, R3, R4), cuál genera la mayor recaudación (suma de `monto_bs`) en un solo mes.

### Comando CQL + agregación

**PowerShell (laptop A — Windows):**
```powershell
# Desde: cualquier directorio
docker exec semapa-cassandra cqlsh --request-timeout=120 -e "USE semapa; SELECT tarifa_alias, periodo, monto_bs FROM consumo_mensual_por_contrato WHERE tarifa_alias IN ('R1','R2','R3','R4') ALLOW FILTERING;" |
  Select-String '\|' | Select-Object -Skip 1 |
  ForEach-Object { $p = $_.ToString().Split('|'); if ($p.Count -ge 3 -and $p[2].Trim() -match '^[\d.]+$') { [PSCustomObject]@{ Cat=$p[0].Trim(); Periodo=$p[1].Trim(); Monto=[double]$p[2].Trim() } } } |
  Group-Object Cat, Periodo |
  ForEach-Object { [PSCustomObject]@{ Grupo=$_.Name; Total=[math]::Round(($_.Group.Monto | Measure-Object -Sum).Sum,2) } } |
  Sort-Object Total -Descending | Select-Object -First 5
```

**bash (laptop B — Linux):**
```bash
# Desde: cualquier directorio
docker exec semapa-cassandra cqlsh --request-timeout=120 -e "USE semapa; SELECT tarifa_alias, periodo, monto_bs FROM consumo_mensual_por_contrato WHERE tarifa_alias IN ('R1','R2','R3','R4') ALLOW FILTERING;" \
  | tail -n +4 | head -n -2 \
  | awk -F'|' 'NF>=3 { gsub(/^ +| +$/,"",$1); gsub(/^ +| +$/,"",$2); gsub(/^ +| +$/,"",$3); key=$1" | "$2; sum[key]+=$3 } END { for (k in sum) printf "%.2f Bs | %s\n", sum[k], k }' \
  | sort -rn
```

### Resultado

```
1684636.49 Bs | R4 | 2026-02   ← máxima recaudación
1656210.23 Bs | R4 | 2026-03
1652624.31 Bs | R4 | 2026-04
1333353.51 Bs | R3 | 2026-02
1314468.32 Bs | R3 | 2026-03
1283466.58 Bs | R3 | 2026-04
 841869.06 Bs | R2 | 2026-02
 840838.27 Bs | R2 | 2026-04
 840824.90 Bs | R2 | 2026-03
 510712.31 Bs | R1 | 2026-02
 504131.88 Bs | R1 | 2026-03
 497097.25 Bs | R1 | 2026-04
```

### ✅ Respuesta

La categoría residencial que más recauda es **R4**, con su pico en **2026-02** generando **1.684.636,49 Bs**. R4 domina en los 3 meses (es la tarifa residencial más alta), seguida por R3, R2 y R1.
